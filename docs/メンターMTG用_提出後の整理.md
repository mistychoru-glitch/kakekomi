## 3. チャットAIとの違い：何を作って、何が分かったか

### 作った4機能

- **B 根拠の提示**: 次の一歩ごとに、公式ページのリンクと確認日（2026-10-09）を付ける。公式サイト以外は出さない
- **D 進み具合の引き継ぎ**: 前回の一歩が「できた／できなかった／まだ」かを保存し、続きから始めると、そこから聞く
- **C 「いまここ」の表示**: 住宅ローン・住まい・税金で、全体の流れのどこにいるかを示す
- **A 個人情報の自動伏せ字**: 電話番号・口座番号などは、AIに送る前に伏せる。保存するまとめには、ブラウザ内で元に戻す

### 実験で分かったこと（Claudeのみ。ChatGPT・Geminiは未実施）

- **内容の広さでは、強い素のAIが勝つ**。これを「勝てる」とは言わない。
- 勝てるのは、次の4点：
  1. **毎回同じ次の一歩が出る**（再現性。実験では40回中40回）
  2. **軽いモデル（Haiku）でも、制度の抜けが出ない**（判断をコードに持たせているため）
  3. **短く、動き出せる**（読み切れる長さ）
  4. **設計で守る**（攻撃・個人情報・番号の捏造をコードで止める）
- 言い方は「答える」ではなく「動き出せるようにする」。
