# Kakekomi 仕様書（How To Use）

公開URL: **https://kakekomi-worker.misty-choru.workers.dev**（スマホ・PCのブラウザで開けます。インストール不要）

## 1. どんなプロダクトか

お金のことで困っている人が、**匿名で、安心して**、いまの状況を整理するためのAI相談サービスです。
家賃の滞納、借金の返済、事業の資金繰りなどの悩みを書くと、

- 気持ちを受け止めながら、**いま大事なことを1〜2点**に絞って返します
- 会話から**状況（家賃・エリア・収入・届いた通知など）をカードに整理**します
- **次の一歩**と、**相談窓口（「かけると何をしてくれるか」つき）**を案内します
- 相談内容は**サーバーに保存しません**（ブラウザの中だけ）。残したいときは、要約をファイルに保存できます

診断や法律の助言はしません。AIの回答には誤りが含まれることがあるため、制度や金額は必ず窓口で確認してください。

## 2. 使い方（基本）

1. **URLを開く**。初回は「ご利用にあたって」が出ます。内容を読んで「理解して始める」を押します
2. **今の状況を入力**して送信します（PCはEnterで送信、Shift+Enterで改行。スマホではEnterは改行で、「送る」ボタンで送信します。1回2,000文字まで）。
   何を書けばいいか迷うときは、画面中央の**例文ボタン**を押すと入力欄に入ります
3. AIが返信します（5〜10秒ほど。返信中は「…」が動きます）。続けて質問に答えたり、気になることを聞いたりして会話を進めます
4. 右側（スマホでは下）の **「まとめノート」** に、整理された内容が出ます
   - **いまの状況**: 相談の種類、緊急度、家賃、エリア、収入、家族、届いた通知と期限など
   - **次の一歩**: 状況に合った行動と、その注意点
   - **相談窓口の一覧**: 法テラス、自立相談支援機関、金融庁、消費者ホットライン188、日本政策金融公庫、よりそいホットライン など。電話番号はタップすると発信できます。お住まいの市区町村の窓口（自立相談支援機関）は番号が自治体ごとに違うため、番号は載せず、公式の都道府県別一覧へのリンクと、役所への聞き方を案内します（古い番号を案内しないための設計です）

## 3. 画面の機能

| 場所 | 機能 |
|---|---|
| ヘッダー「相談内容を保存する」 | 会話をAIが要約し、保存のしかたを選べます。**ファイルに保存**（あとで読み込んで続きから相談できます）か、**印刷・PDFにする**（窓口や専門家に見せるため）。サーバーには残りません |
| 最初の画面「前回の相談の続きから始める」 | 「相談内容を保存する」で保存したファイル（.md）を選ぶと、要約といまの状況カード・次の一歩を元に戻して、続きから相談できます。ファイルはブラウザの中で読み込まれ、サーバーには保存されません |
| まとめノートの「いまの位置（目安）」 | 家賃・住宅ローン・税金や保険料の滞納が進む**一般的な流れ**の上に、**いまの位置と、その段階で取れる手**を出します（例: 住宅ローンなら、督促状→催告書→一括返済の請求→代位弁済→競売）。位置は、届いた通知と滞納の月数から、決まったルールで決めます（AIは使いません）。期間や手続きは契約や会社で異なるので、すべて「目安」と添えます |
| 「次の一歩」の根拠と進み具合 | 一歩ごとに、**公式ページへのリンクと確認日**を出します（確認できていない一歩には出しません）。「まだ／やった／できなかった」を選べます。保存ファイルに入り、**続きから再開すると、「前回の一歩は、その後どうなりましたか」から始まります** |
| 入力欄の「AIには伏せて送ります」 | 電話番号、メールアドレス、口座番号、マイナンバー、カード番号、番地、生年月日に見える部分は、**AIに送る前に自動で伏せ字**にします。**あなたの画面には、そのまま残ります**。「伏せて送りました」と表示します。氏名など、見分けられないものがあるので、完全ではありません |
| まとめノートの「電話で話す内容をつくる」 | いまの状況から、**電話の台本**（かける先・最初の一言・伝えること・聞くこと・用意するもの）を作ります。AIは使わず、状況の値を決まった型に当てはめるので、すぐ出て、事実にない内容が混ざりません。番号は確認済みの窓口だけです。印刷・PDFにも入ります |
| 最初の画面「資金繰りチェック」（経営者向け） | 手元の資金、毎月の支出、今後3か月の入金の見込みから、**資金が足りなくなる時期と不足額**を試算します。次の一歩（銀行への返済スケジュールの相談、公庫・よろず支援拠点、入金を早めたい取引先の順番、**支払いの猶予を相談する取引先の優先順位**）も出します。計算は**AIを使わず、ブラウザの中だけ**で行い、**数字も取引先名もサーバーとAIに送りません**。取引先の一覧は、表から貼り付けるか、CSVファイルで取り込めます（文字コードは自動判断）。画面には取引先名をそのまま表示し、**印刷・PDFでは名前を伏せることを選べます**。入力は保存しないのが初期状態です |
| ヘッダー「新しい相談を始める」 | 今の会話と状況カードを消して、最初からやり直します（確認が出ます） |
| ヘッダー「ログイン / 登録」 | アカウントの作成・ログイン（任意。次の項目） |
| チャット下「ご利用にあたって」 | 免責・データの扱いをいつでも再表示します |

## 4. アカウント（任意）

**ログインしなくても、すべての機能を使えます。** アカウントは、今後の機能（利用量に応じた上限の設定など）のための土台です（§6参照）。

- **新規登録**: メールアドレス、表示名、パスワード（8文字以上、英字と数字の両方を含む）を入力します
  - メールアドレスは、ログインIDとして使うだけで、メールは送信されません
  - 登録が完了すると、**リカバリーコード**（例: `XXXX-XXXX-XXXX-XXXX`）が**1回だけ**表示されます。コピーかファイル保存をして、「控えました」にチェックしてから閉じます
- **ログイン / ログアウト**: ヘッダーから行います（ログインは30日間有効）
- **パスワードを忘れたとき**: ログイン画面の「パスワードを忘れた方はこちら」から、メールアドレス・リカバリーコード・新しいパスワードを入力します。再設定すると、新しいリカバリーコードが発行されます

## 5. 試してみる入力例（動作確認用）

| 試したいこと | 入力例 | 期待される動作 |
|---|---|---|
| 家賃の相談 | 「家賃を2か月滞納して、大家さんから督促状が届きました。手取り25万円で、家賃は20万円です」 | 状況カードに家賃・収入・通知が整理され、次の一歩（自立相談支援機関への相談など）と窓口が案内される |
| 住宅ローンの滞納 | 「自宅のローンを6か月滞納していて、保証会社から一括で返すようにという通知が届きました」 | 状況カードに「住宅ローン」「6か月分」「一括返済を求める通知」が出る。次の一歩に、借入先・保証会社への確認と、法テラスなどの専門家相談（任意売却・個人再生などの検討）が出る。競売の通知なら、最優先で専門家相談が出る |
| 税金・保険料の滞納 | 「住民税と国民健康保険料を滞納していて、市役所から差押えの予告が届きました」 | 状況カードに「税・保険料の滞納」「差押えの予告」が出る。次の一歩に、書面の送り主への至急の連絡（分割・猶予の相談）と、市区町村の窓口が出る。国税なら税務署、年金なら免除・納付猶予の案内になる。窓口の一覧に、公式の案内ページへのリンクが出る |
| 資金繰りチェック | 最初の画面の「資金繰りチェック」で、手元の資金150万円・毎月の支出450万円・入金の見込み300万円などを入れる | 資金が足りなくなる月と不足額が出る。支払い先の一覧を入れると、猶予を相談する順番が出る（給与・税金・借入の返済は、取引先への猶予の対象にせず、専用の窓口や専門家を案内する） |
| 借金の相談 | 「借金の返済が苦しくて、毎月の支払いに追われています」 | 次の一歩に「法テラスへの相談」が出る。借入が複数なら、債務整理の方法がメリット・デメリットつきで提示される |
| 事業の資金繰り | 「個人事業主で、来月の支払いの資金繰りが厳しいです」 | 事業向けの窓口（商工会議所・よろず支援拠点・公庫）が案内される |
| 相場の比較 | 「家賃20万円は高い気がします。他のエリアの相場と比べたいです」 | AIがWeb検索で相場を確認して答える（時間が少しかかる） |
| 範囲外の依頼 | 「猫の画像を生成して」 | お金の相談に絞っているため、丁寧に断られる |
| 安全機能の確認 | 命に関わる表現（例:「消えてしまいたい」） | AIを使わず、よりそいホットライン等の**固定の案内**が最優先で表示される |
| 保存 | 数往復の会話のあとに「相談内容を保存する」 | 要約と次の一歩を含むMarkdownがダウンロードされる |
| 続きから相談 | 保存したファイルを「前回の相談の続きから始める」で選ぶ | 状況カードが復元され、前回の内容を踏まえた返信が来る |

## 7. 利用上の注意・制限

- AIによる情報整理であり、**法律・税務などの専門的な助言ではありません**。回答には誤りが含まれることがあります
- 入力した内容は、回答を作るために**AI事業者（Anthropic社）のサービスに送信**されます。電話番号・メール・口座番号などに見える部分は、送る前に自動で伏せますが、完全ではありません。氏名・住所・口座番号など、個人を特定できる情報は入力しないでください
- 会話は**サーバーに保存されません**。ブラウザのデータ削除や「新しい相談を始める」で消えます
- サービスの改善のため、**日ごとの利用件数（相談の開始数・送信数など）だけ**を記録します。会話の内容、IPアドレス、メールアドレスなど、個人を特定できる情報は記録しません
- 乱用防止のため、同じネットワークからの利用回数に上限があります（超えると案内が出ます）。全体の1日の利用上限もあり、超えた日は「明日またお試しください」と表示されます
- 相談窓口の電話番号・受付時間は、2026年10月時点の公式情報です
